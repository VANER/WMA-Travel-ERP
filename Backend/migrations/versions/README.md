# Revisions Alembic

As revisions da Fase 2 serão adicionadas aqui somente quando uma mudança estrutural real for aprovada. A
baseline certificada da Fase 1 não deve ser recriada como revision Alembic.

Cada arquivo usa o padrão `YYYYMMDDHHMM_descricao_curta.py`, revision ID equivalente e encadeamento linear por
`down_revision`. Múltiplos heads não são permitidos sem decisão arquitetural explícita.
