# Migrations da Fase 2

Este diretório contém somente evoluções posteriores à baseline certificada da Fase 1. O diretório `versions/`
permanece vazio até existir uma alteração estrutural real; o dump oficial não deve ser representado novamente
como uma migration inicial.

As regras operacionais, a nomenclatura e o processo de validação estão em `Docs/MIGRATIONS.md`.
